# iSDR repository working policy

- Use `OpenARDF/iSDR` as the sole active development repository for iSDR.
- Before editing, confirm that `origin` is `https://github.com/OpenARDF/iSDR.git`.
- Create all development branches, code changes, tests, commits, pull requests,
  releases, and related documentation in this public repository.
- Treat `OpenARDF/iSDR-Archive` as read-only historical evidence. Do not create
  branches, commits, tags, or releases there.
- Inspect the private archive only when historical evidence is necessary. If a
  compelling archival correction appears necessary, explain why this public
  repository cannot satisfy the task and obtain the user's explicit approval
  before modifying or pushing to the archive.
- Never merge or publish the archive's Git history. When historical source is
  needed, bring only the necessary, provenance-cleared content into this public
  repository through its normal review workflow.
